# تطبيق الجوال (Google Play / App Store)

غلاف تطبيق جوال حول صفحة "اطلب الآن" العامة (`/order`) عبر
[Capacitor](https://capacitorjs.com) — يحمّل الصفحة المنشورة فعلياً
مباشرة (`server.url` في `capacitor.config.ts`) بدل تجميع نسخة ثابتة، فأي
تحديث يُنشَر على الموقع (خدمة جديدة، سعر، تصميم) ينعكس في التطبيق فوراً
بلا حاجة لإصدار تحديث على المتاجر.

## ما تم إعداده بالفعل

- `capacitor.config.ts` — appId مبدئي `com.zaha.app`، اسم التطبيق "زهى".
- `android/` — مشروع أندرويد ستوديو كامل (Gradle)، بما فيه الأيقونات
  وشاشة البداية (Splash) بألوان العلامة التجارية (فاتح/داكن).
- `ios/` — مشروع Xcode كامل، بنفس الأيقونات والألوان.
- `resources/icon.png` و `resources/icon-foreground.png` — المصدر الذي
  تُولَّد منه كل الأيقونات (`npx @capacitor/assets generate`) — إن غيّرت
  الشعار لاحقاً، استبدل هذين الملفين وأعد التوليد بنفس الأمر.

## الخطوات المتبقية (تحتاج أدوات لا تتوفر في بيئة التطوير هذه)

### أندرويد

1. ثبّت [Android Studio](https://developer.android.com/studio) على أي
   جهاز ويندوز/ماك/لينكس.
2. `npm run cap:open:android` يفتح المشروع في Android Studio مباشرة
   (أو افتح مجلد `android/` يدوياً).
3. من Android Studio: **Build → Generate Signed Bundle/APK** لإنشاء ملف
   `.aab` (النوع المطلوب من Google Play).
4. أنشئ حساب [Google Play Console](https://play.google.com/console)
   (رسوم مرة واحدة 25$)، ثم أنشئ تطبيقاً جديداً وارفع الـ `.aab`.

### آيفون

**يتطلب جهاز Mac فعلياً** — Xcode لا يعمل إلا على macOS، ولا توجد طريقة
لتجاوز هذا القيد.

1. على جهاز Mac: `npm run cap:open:ios` يفتح المشروع في Xcode.
2. أنشئ حساب [Apple Developer Program](https://developer.apple.com/programs/)
   (رسوم سنوية 99$، يتطلب توثيق السجل التجاري للشركة).
3. من Xcode: **Product → Archive** ثم **Distribute App** للرفع مباشرة
   إلى App Store Connect.

### قبل الرفع الفعلي على أي من المتجرين

- **appId نهائي**: راجع `com.zaha.app` في `capacitor.config.ts` — يصبح
  ثابتاً بعد أول رفع فعلي ولا يمكن تغييره لاحقاً لنفس التطبيق.
- **سياسة الخصوصية**: كلا المتجرين يشترطان رابط صفحة سياسة خصوصية علنية
  (لا توجد حالياً في الموقع — تحتاج صفحة جديدة، بسيطة، تشرح ما البيانات
  التي تُجمَع من العميل عند الطلب واستخدامها).
- **لقطات شاشة ووصف**: كل متجر يطلب لقطات شاشة فعلية للتطبيق (بأحجام
  محددة لكل مقاس جهاز) ووصفاً تسويقياً قصيراً وطويلاً.
- **نموذج أمان البيانات (Google) / بطاقة الخصوصية (Apple)**: نماذج
  إفصاح قياسية عن نوع البيانات المُجمَّعة (اسم، جوال، عنوان) — تُملأ من
  لوحة كل متجر مباشرة، ليست ملفاً في المشروع.

## أوامر مفيدة

```bash
npm run cap:sync          # يزامن إعدادات capacitor.config.ts مع مجلدي android/ios بعد أي تعديل عليه
npm run cap:open:android  # يفتح مشروع أندرويد ستوديو (يتطلب Android Studio مثبَّتاً)
npm run cap:open:ios      # يفتح مشروع Xcode (يتطلب Mac)
```
